# STYLEE 🛍️
### A Fashion Shopping Website

STYLEE is a frontend fashion shopping website that I built during my 12th-grade vacation as a personal project while exploring web development.

The idea was to create a simple online clothing store where users can explore different fashion collections, browse products and interact with a shopping cart.

This project was independently designed and coded by me using HTML, CSS and JavaScript.

## ✨ Features

- **Homepage:** Fashion banners, image slideshow and featured collections.
- **Multiple Collections:** Separate sections for kids', men's and women's fashion.
- **Summer Collection:** Dedicated page showcasing summer outfits.
- **Trending Offers:** A page for exploring trending fashion products.
- **Shopping Cart:** Add products, adjust quantities, remove items and calculate the total price.
- **Search Interface:** A separate page for exploring products.
- **Login & Sign-up Pages:** Frontend form interfaces.
- **CSS Styling:** Custom layouts, hover effects, transitions and visual styling.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layouts, animations and responsiveness |
| JavaScript | Shopping cart interactions and dynamic behaviour |

No additional dependencies or installations are required.

## 📌 Project Scope

This is a frontend learning project, not a complete production-ready e-commerce application.

The login and sign-up interfaces are not connected to a backend authentication system. There is no integrated payment gateway or order-processing system.
